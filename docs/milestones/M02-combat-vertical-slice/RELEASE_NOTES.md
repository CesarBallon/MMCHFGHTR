# M02 release notes

Status: **Draft**

M02 will deliver the first production-quality Mamacha Fighter matchup: Benita versus Saja. It focuses on responsive, readable combat; fluid authored animation; complete grounded and airborne movement; throws, blocks, specials and supers; and deterministic behavior suitable for later rollback networking.

This initialization does not change the playable build. Runtime changes will arrive through reviewed slices linked to issue #15.

## Compatibility

- Existing eight-fighter M01 content remains the fallback baseline.
- Replay format changes, if required, must be versioned and documented.
- New animation or collision schemas require forward and rollback notes.

## Migration

None for the initialization slice.

## Known limitations

The remaining six fighters retain baseline-quality combat presentation during M02.
