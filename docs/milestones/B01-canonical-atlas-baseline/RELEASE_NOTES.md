# B01 release notes

This baseline consolidates Mamacha Fighter around the latest approved roster artwork and the completed eight-fighter action-atlas pass. Every fighter now enters the shared repository with current locomotion, combat and both special-move atlases, plus the matching selection stance and face portrait.

Earlier selection experiments, idle studies, superseded roster cutouts and raw conversion inputs have been removed from the collaborative repository. They remain available in a separately verified full-history backup, so the cleanup does not erase project history.

There are no intentional combat-rule changes in B01. Its purpose is to establish a clear, reviewable source of truth for all subsequent engineering and content work.
