# M00 release notes

Mamacha Fighter’s prototype baseline establishes the full eight-fighter roster, each fighter’s two signature moves, assigned home stage and soundtrack, local controller/keyboard play, and a complete first pass of locomotion and combat action atlases.

This is a preserved development baseline, not the public online release. It does not yet include story campaigns, final bosses, remote multiplayer, accounts or rankings. Its purpose is to protect the visual identity and playable behaviors already established while the codebase is converted into a deterministic, testable production architecture.
