# M00 changelog

## Gameplay

- Eight distinct playable fighters: Saja, Benita, Mariachay, Asunta, Shabuka, Bella, Jarjacha and Coraima
- Movement, jumping, crouching, blocking, hit reactions, light/heavy attacks and two signature specials per fighter
- CPU arcade and two-player local versus
- Round timer, health, meter, hit stop, projectiles, particles and screen shake

## Presentation

- Canonical character cutouts, close-up selection portraits and stance-focused selection presentation
- Eight home stages with fighter-specific assignments
- Full stereo supplied themes, intro/selection music and end credits music
- Keyboard, touch and standard Gamepad API controls

## Production assets

- Four runtime WebP action atlases per fighter
- Canonical/source PNG atlases retained separately from runtime exports
- Static, dependency-free browser build in `dist/`
