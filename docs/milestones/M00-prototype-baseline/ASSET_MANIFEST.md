# M00 asset manifest

## Canonical roster

Canonical fighter models are stored under `source-assets/canonical-models-v16/` for:

Saja, Benita, Mariachay, Asunta, Shabuka, Bella, Jarjacha and Coraima.

Runtime selection assets are in:

- `dist/assets/fighters/select-v16/`
- `dist/assets/fighters/portraits-v16/`

Action atlases are under `source-assets/action-atlases/<fighter>/` with optimized WebP exports under `dist/assets/fighters/actions/<fighter>/`. Each fighter has locomotion, combat and two named-special atlases.
