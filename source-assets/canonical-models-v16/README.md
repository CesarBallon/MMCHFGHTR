# Canonical fighter models — v16

These eight transparent PNG illustrations are the authoritative visual references for Saja, Benita, Mariachay, Asunta, Shabuka, Bella, Jarjacha, and Coraima. Selection portraits, breathing-idle atlases, and future combat artwork should preserve their faces, costumes, body proportions, silhouettes, props, and color palettes.

Saja, Benita, and Mariachay were replaced with the revised user-supplied masters in the v17 roster update.

Benita was replaced again with the latest user-supplied full-body master in the v18 asset update.

Jarjacha became the canonical fighter for this roster slot in the v19 update. Her supplied transparent full-body illustration is the sole visual reference for every current asset.
