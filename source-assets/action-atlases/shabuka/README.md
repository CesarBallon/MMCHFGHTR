# Shabuka action atlases

- `locomotion.png`: rooted power stance, heavy walk, crouch, and jump.
- `combat.png`: straight punch, hammer blow, block, and hit reaction.
- `pom-power.png`: sixteen sequential pom-pom projectile frames.
- `rising-cheer.png`: sixteen sequential rising-uppercut frames.

Rendered at 16 fps with interpolation, automatic opponent-facing mirroring, and a separate grounded shadow.
