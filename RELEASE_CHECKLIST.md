# Release checklist

- [ ] Milestone exit criteria and packet are complete
- [ ] Changelog and release notes are current
- [ ] `npm test` passes from a clean checkout
- [ ] Required pull-request and code-owner approvals are present
- [ ] Browser/controller matrix and online soak tests pass for the release scope
- [ ] New assets have provenance, rights and optimized runtime exports
- [ ] Security/privacy review is complete for account or data changes
- [ ] Database migration and rollback were rehearsed when applicable
- [ ] Git tag identifies the exact release commit
- [ ] Sites/source host contains the exact release commit
- [ ] Saved Site version number and ID are recorded
- [ ] Deployment audience and approval are explicit
- [ ] Monitoring, incident contact and rollback target are ready
- [ ] Production deployment ID and smoke-test evidence are recorded
